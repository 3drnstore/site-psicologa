# Site Psicóloga

Projeto do site público, área do paciente e painel administrativo para gestão de consultas.

## Stack inicial

- React + TypeScript
- Vite
- Preparado para deploy na Cloudflare
- Integrações planejadas: autenticação, D1, gateway de pagamento e Google Calendar

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

O diretório de saída é `dist`.
